# Manual do Sistema de Gestão de Acesso (SGA)

## Entidades Privadas sem Fins Lucrativos

Bem-vindo ao Manual do Sistema de Gestão de Acesso (SGA).

Este manual apresenta orientações para utilização do Sistema de Gestão de Acesso (SGA) pelas entidades privadas sem fins lucrativos que recebem recursos públicos por meio de convênios ou instrumentos congêneres.

Utilize o menu lateral para navegar pelas seções do manual.
